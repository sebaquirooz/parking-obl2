# Proyecto: Sistema de Parking en Java

Este proyecto corresponde al curso **Programación 2**.
El objetivo es desarrollar una **interfaz en Java** que simula el funcionamiento completo de un estacionamiento (*parking*), gestionando la entrada y salida de vehículos, el cálculo de tarifas y la disponibilidad de plazas.

El sistema está implementado **sin base de datos**, trabajando únicamente con estructuras de datos en memoria para administrar toda la información necesaria.
